## Decisions already made

- **`readFolderFacts`.** In `Options.ini`, section `[options]`: `modsdisabled` `0` is mods `on`, `1` is `off`;
  `scriptmodsenabled` `1` is `on`, `0` is `off`; a missing key is `missing`. `gameUpdatedAt` is the date of
  `<install>/Game/Bin/TS4_x64.exe`; `thumbCacheAt` the date of `localthumbcache.package`. Missing files give `null`.
- **One finding per rule**, with all its files, never one per file. The exception is `log-names-mod`: one per group.
- **`runRules` is pure**, and returns findings sorted `stop`, `warn`, `info`, then in the order below.

| Rule | Fires when | Severity, certainty | Fix | Next |
|---|---|---|---|---|
| `mods-off` | options read, mods or script mods `off`, and at least one package or script exists | stop, file-problem | `turn-mods-on` | none |
| `folder-in-onedrive` | `folder.inOneDrive` | warn, worth-testing | none | none |
| `two-sims-folders` | `otherFolders` is not empty | warn, worth-testing | none | pick-folder |
| `log-names-mod` | a `modHint` matches a script entry in exactly one group (see below) | warn, likely | `disable-group` | none |
| `script-too-deep` | a script with `depth > 1` | warn, file-problem | `move-script-up` | none |
| `package-too-deep` | a package deeper than `maxPackageDepth` (`missing` counts as 5; `unreadable` skips the rule) | warn, file-problem | none | none |
| `archive-in-mods` | any `archive` file | warn, file-problem | `set-aside-files` | none |
| `broken-package` | a package or script with status `broken` | warn, file-problem | `set-aside-files` | none |
| `wrong-game-package` | a package with status `wrong-game` | warn, file-problem | `set-aside-files` | none |
| `duplicate-files` | two or more files with the same `sha256` | warn, file-problem | `set-aside-files` (the extra copies) | none |
| `script-older-than-update` | a script whose `modifiedAt` is before `gameUpdatedAt` | info, worth-testing | none | none |
| `stale-thumbnail-cache` | the newest mod file is newer than `thumbCacheAt` | info, file-problem | `clear-caches` | none |
| `crash-without-cause` | a `crash` log exists and no `log-names-mod` finding fired | warn, worth-testing | none | fifty-fifty |

- **Matching a `modHint`.** Take each script entry without its extension, lowercased (`wicked_wardrobe/outfit_picker`).
  The hint matches when it ends with `/` + that text. Entries named only `__init__` never match. The longest match
  wins. A hint that matches entries in two groups names nobody. A file with status `unreadable` is never "broken".
- **Which duplicate stays.** Keep the copy in a CurseForge group, else the shallowest, else the first by name. The
  fix lists the others.
- **Words.** `src/shared/copy/findings.ts` holds one function per rule that returns `title` and `detail` from counts
  and names. Calm, no blame, no jargon, no error codes. `mods-off` says "Don't save your game until mods are back
  on." `script-older-than-update` says it is a hint, not proof. `crash-without-cause` says the game did not say
  which mod, and that the 50/50 test can find it. Paths, module names and category ids go in `evidence` only.
