## Decisions already made

- **`runScan`:** `Mods` is `<folder.path>/Mods`. Run inventory, logs and folder facts, then the rules. Send progress
  for `counting`, `mods`, `logs`, `rules`. A thrown error becomes `{ status: 'failed', why: 'unexpected' }`; it never
  escapes. Fill `tookMs`.
- **Handlers.** `locate:run` calls PR 3's `locate(ctx.host)`. `scan:run` and `settings:update` accept a `folderPath`
  only when `locate` finds that folder now. `scan:run` stores the scan in `ctx.session.scan`. Settings live in
  `<stateDir>/settings.json`, written through `ctx.gate` (`reason: 'state'`, `folderPath: null`).
- **Report zip.** Name: `Sims Helper report <yyyymmdd-hhmmss>.zip`, on her Desktop. It holds exactly: every log
  file the scan read, `Options.ini`, `GameVersion.txt`, `scan.json` (the scan), and CurseForge's
  `AddonGameInstance.json`. No other CurseForge file, ever: they can hold sign-in tokens. Run every entry name and
  every text content through `ctx.redact`. Skip a file over 8 MB and name it in `skipped.txt`. Build the zip in
  memory with `fflate` and write it with one gate request (`reason: 'report'`, a `write` op with `mode: 'create'`).
- **Start.** `settings:get`, then: `welcome` when not seen; else `pick-folder` when locate finds more than one folder
  and none is chosen; else `what-happened`.
- **Screens.**
  - *Welcome:* "Hi Lila! Tyler made this so your game can stop crashing. Let's take a look at your mods."
  - *Pick folder:* one card per folder with its path and "last used" date; the newest is marked. No folder found: a
    plain message and what to do.
  - *What happened?:* the five `Symptom` choices as big buttons.
  - *Check-up:* scans whenever `session.scan` is `null`, with two-phase progress ("Counting files…", then "Checking
    mod 1,420 of 5,300"). Then one verdict line, and finding cards grouped "Do this first", "Worth fixing", "Good to
    know". A card shows title, detail, the certainty badge, `<FindingActions finding />`, a closed "Technical
    details" box and the file list. Under the cards: `<FiftyEntry scan />`, `<AskEntry scan />`, and "Send to Tyler".
    When the game is running, a calm note says looking is safe.
  - *Send to Tyler:* one line on what the zip holds (logs and the mod list, no saves, her name removed), a button,
    then the file name and "Show on Desktop".
  - *About:* the dedication, plus "Independent helper tool for The Sims 4. Not affiliated with or endorsed by
    Electronic Arts or Maxis."
