# Moving one The Sims 4 save between Windows PCs

Checked 2026-11-24. EA Help and provider docs establish supported behavior. EA Forums posts provide examples. Inferences and unverified cases are marked below.

## What travels

- **Current save.** In the active Windows Documents folder, open `Electronic Arts\The Sims 4\saves`. One manual slot's playable snapshot is `Slot_XXXXXXXX.save` (eight hexadecimal digits). The same stem can have up to five optional snapshots named `.save.ver0` through `.save.ver4`, newest to oldest. Copy the current file to play it and include the matching backups only if recovery history is wanted. The in-game Load Game screen offers Recover Save for prior manual save points. Check the actual Documents location, which can be redirected by OneDrive. [EA Forums Windows guide](https://forums.ea.com/kb/the-sims-helpers-blog-en/%E2%9A%99%EF%B8%8Fpc-sims-4-missing-user-content-saves-mods-etc-/12636780) · [EA Help recovery](https://help.ea.com/en/articles/the-sims/the-sims-4/how-to-restore-a-previous-saved-game/)
- **Autosave is separate.** EA's current recovery guide describes one rolling autosave slot with no recoverable older autosaves. The Windows forum guide describes an obsolete historical autosave file, `Slot_00000001.save`. Those descriptions concern different points in the game's history. The current autosave filename was unconfirmed. An explicit manual save gives the player a specific slot to hand off. [EA Help recovery](https://help.ea.com/en/articles/the-sims/the-sims-4/how-to-restore-a-previous-saved-game/) · [EA Forums Windows guide](https://forums.ea.com/kb/the-sims-helpers-blog-en/%E2%9A%99%EF%B8%8Fpc-sims-4-missing-user-content-saves-mods-etc-/12636780)
- **Other folders.** `Tray` holds separately saved My Library households, lots, and rooms. It is needed to bring those library entries along. EA's save transfer instructions copy only `saves`, so the placed households and builds in that playthrough travel with the slot. Mods/CC need separate installation for the same experience. Options, screenshots and caches are outside the slot transfer. A mod may keep additional data outside the slot, so check the creator's instructions for each significant gameplay mod. [EA transfer FAQ](https://www.ea.com/games/the-sims/the-sims-4/faq) · [EA Forums Windows guide](https://forums.ea.com/kb/the-sims-helpers-blog-en/%E2%9A%99%EF%B8%8Fpc-sims-4-missing-user-content-saves-mods-etc-/12636780)
- **Size.** Anecdotal examples range from about 18 MB for a long-running legacy save to about 220 MB for a reported bloated save. Another thread discusses roughly 40–50 MB and flags 100 MB-plus as possible bloat. Tens of MB per snapshot is a planning estimate from examples. Measure the selected file and optional history before offering email. Five similarly sized backups can bring the total to about six times the current snapshot's size. No official typical size or maximum found. [EA Forums save-size examples](https://forums.ea.com/discussions/the-sims-4-technical-issues-pc-en/i-cant-save-my-game-anymore/4963193) · [EA Forums discussion of bloat](https://forums.ea.com/discussions/the-sims-4-technical-issues-pc-en/re-lag-in-sims-4-increasing-over-time/11807599)
- **Running game.** Use **Save, then exit**, and copy after the game closes. Keep it closed while placing the received file. I found no documented live-copy guarantee or evidence about atomic writes during save rotation. Inference: a copy while the game is running captures disk state only and can race a manual save, autosave or backup rotation. [EA Help recovery and autosave behavior](https://help.ea.com/en/articles/the-sims/the-sims-4/how-to-restore-a-previous-saved-game/)

## Compatibility and EA accounts

- **Windows to Windows works by copying the save.** Place the file in the receiving Windows user's active `saves` folder and open it via Load Game. For the closest continuation, use the same game patch and the same enabled packs, mods and CC versions. EA documents manual transfers even between PC and Mac. **EA app cloud saves for The Sims 4 on PC are unsupported** according to EA's current FAQ. Third-party file sync is separate. [EA transfer FAQ](https://www.ea.com/games/the-sims/the-sims-4/faq) · [EA Forums Windows transfer](https://forums.ea.com/discussions/the-sims-4-technical-issues-pc-en/i-saved-a-gameon-my-laptop-why-isnt-it-available-to-play-on-my-desktop/11823414)
- **Packs and mods.** EA documents that playing with required packs deactivated can remove objects, clothing and pack-specific traits, and make pack worlds and gameplay unavailable. Households from a deactivated world can still appear in Manage Households. Missing or disabled CC disappears from view, and EA warns that saving with mods or CC disabled can remove content from the saved game. Keep the untouched source and restore missing dependencies before playing the transfer. These sources establish content/progress loss. They provide no general rule that missing packs alone corrupt the file, or a guarantee that arbitrary mod-dependent saves can load safely. [EA Help on packs](https://help.ea.com/en/articles/the-sims/the-sims-4/pack-install/) · [EA Help on mods](https://help.ea.com/en/articles/the-sims/the-sims-4/mods-and-the-sims-4-game-updates/) · [EA Forums recovery after missing DLC](https://forums.ea.com/discussions/the-sims-4-technical-issues-pc-en/missing-save-following-update-ts4/11810524)
- **EA account.** For EA-app purchases, the player can sign into her own EA account on the second PC and install her owned packs via Library → The Sims 4 → Manage → Manage add-ons. Check that they are active in-game. Steam-linked purchases can require the corresponding Steam installation, so check the original storefront. EA makes the account personal and the account holder responsible for its use. Concurrent EA app users report a second sign-in logging the first PC out. No current official Sims 4-specific rule confirming simultaneous play behavior, especially offline, was found. Plan for one active session and have the account holder do her own sign-in. [EA Help pack installation](https://help.ea.com/en/articles/the-sims/the-sims-4/pack-install/) · [EA Forums DLC and storefront guide](https://forums.ea.com/kb/the-sims-helpers-blog-en/%E2%9A%99%EF%B8%8Fpc-mac-sims-4-missing-content-dlc/12636720/) · [EA User Agreement §1](https://www.ea.com/legal/user-agreement) · [EA Forums concurrent login reports](https://forums.ea.com/discussions/ea-app-general-discussion-en/why-cant-i-have-multiple-computers-logged-in-on-the-ea-app/7508916)

## Transfer options

| Option | Player setup and limits |
| --- | --- |
| Email | Lowest setup for an occasional small file. Personal Gmail allows 25 MB total attachments and substitutes a Drive link above that. Outlook.com caps the whole message at 25 MB and offers OneDrive links for larger files. Microsoft documents a 20 MB whole-message limit in Outlook for internet accounts. Leave room for message overhead. The destination PC can retrieve the message later. Each message is a separate snapshot, so name it clearly. [Gmail](https://support.google.com/mail/answer/6584) · [Outlook.com](https://support.microsoft.com/en-au/support/known-issues/unable-to-attach-files-in-outlook-com) · [Outlook client](https://support.microsoft.com/en-us/outlook/reduce-attachment-size-to-send-large-files-with-outlook) |
| Drive website or Drive for desktop | Upload a snapshot and share with a specific Google account, or install Drive for desktop on both PCs and put exports in a dedicated My Drive handoff folder. On the same account, My Drive can stream or mirror. With separate accounts, share access explicitly and confirm the receiving workflow. Streamed files need network access unless marked available offline. Wait until the upload and download finish before use. Uses the account's storage quota. Desktop folder approach requires no OAuth integration in the helper. [Google sharing](https://support.google.com/drive/answer/2494822) · [Drive for desktop](https://support.google.com/drive/answer/10838124) · [Stream or mirror](https://support.google.com/drive/answer/13401938) |
| Drive API in the helper | A browser sign-in on each PC is simple once built. Developer setup includes a Google Cloud project, enabling Drive API, an OAuth desktop client and the installed-app browser flow with PKCE and a loopback callback. Use `https://www.googleapis.com/auth/drive.file`, Google's non-sensitive per-file scope, for files the app creates or the user explicitly opens/shares with it, such as via Picker. It grants no blanket access to existing Drive files. For two Google accounts, explicitly share the exports and authorize the receiving app to open them. [Drive scopes](https://developers.google.com/workspace/drive/api/guides/api-specific-auth) · [Installed app OAuth](https://developers.google.com/identity/protocols/oauth2/native-app) |
| Synology NAS | If already owned, install Drive Server, create an account/share with limited access, and set up Drive Client on both PCs for a handoff folder. Same LAN can connect locally. Away from home, QuickConnect uses an ID and may relay traffic if a direct path fails. The NAS must be online for upload/download. Tailscale is an alternative with a package on the NAS, clients on the PCs, and access granted through the private network. Tailscale can relay when direct paths fail and generally requires no inbound ports. Public port forwarding takes router and TLS setup and exposes a service. QuickConnect or Tailscale can avoid that for this use. [Synology Drive connections](https://kb.synology.com/DSM/tutorial/How_to_set_up_connection_to_Drive) · [QuickConnect relay](https://kb.synology.com/en-us/WP/Synology_QuickConnect_White_Paper/4) · [Tailscale on Synology](https://tailscale.com/docs/integrations/synology) · [Tailscale firewall guidance](https://tailscale.com/docs/reference/faq/firewall-ports) |
| App to app | **Design inference.** Same reachable LAN, including Ethernet, can work without a hosted service. Both apps must be open. Pair the receiver and require it to accept the transfer. Windows firewall or guest Wi-Fi isolation can block it. Across the internet, an overlay like Tailscale provides a reachable private network with another install and sign-in. A standalone implementation can use signaling and WebRTC ICE/STUN with TURN relay fallback, which adds operational work. If the PCs are never online together, use storage that holds the snapshot between sessions. [WebRTC peer connections](https://webrtc.org/getting-started/peer-connections) · [WebRTC relay](https://webrtc.org/getting-started/turn-server) · [Tailscale connectivity](https://tailscale.com/docs/reference/device-connectivity) |

**Drive verification.** The non-sensitive `drive.file` scope avoids sensitive/restricted-scope review. Google documents a personal-use verification exemption and treats consent-screen branding separately. A private one- or two-user app appears to fit that exemption. External projects left in Testing issue seven-day refresh tokens for Drive scopes, so expect weekly reauthorization in Testing. Confirm the actual consent and publishing behavior with the intended accounts before choosing this route. [Google brand verification and exemptions](https://developers.google.com/identity/protocols/oauth2/production-readiness/brand-verification) · [Google refresh-token limits](https://developers.google.com/identity/protocols/oauth2)

## Protecting progress

1. **Two versions of one save.** If both PCs edit the same starting snapshot, they produce two independent histories. Inference: the newest timestamp alone cannot resolve the conflict and choosing one drops progress from the other. Use a deliberate handoff after save and exit. For a future two-way flow, remember the last common snapshot, detect changes on both PCs, and keep both copies for the player to choose. No supported Sims save merge was found. [EA local transfer FAQ](https://www.ea.com/games/the-sims/the-sims-4/faq) · [EA Forums on sync renames](https://forums.ea.com/kb/the-sims-helpers-blog-en/%E2%9A%99%EF%B8%8Fpc-sims-4-missing-user-content-saves-mods-etc-/12636780)
2. **Newer patch on older game.** A newer save can be rejected by an older installation. Compare the version on both main menus and update the receiving game before loading. Match both PCs before returning the save too. The forum error is evidence of a compatibility failure mode, rather than a complete compatibility matrix. [EA Forums newer-save error](https://forums.ea.com/discussions/the-sims-4-technical-issues-pc-en/error-this-save-data-was-created-with-a-newer-version-of-the-game-/11629520/replies/11629522) · [EA Help game version location](https://help.ea.com/en/articles/the-sims/the-sims-4/mods-and-the-sims-4-game-updates/)
3. **Slot collision.** Independent games can assign the same slot filename. Stage each export outside the game folder and keep the receiver's original. During manual placement with the game closed, use an unused valid slot name if a filename collides, checking the primary file and backup suffixes. If carrying recovery history, rename the whole set to the same unused stem. Verify the received snapshot via Load Game. [EA Forums filename and recovery rules](https://forums.ea.com/kb/the-sims-helpers-blog-en/%E2%9A%99%EF%B8%8Fpc-sims-4-missing-user-content-saves-mods-etc-/12636780)

**Project fit.** The current rules prohibit app writes to `Saves/` and `Tray/`. A first pass can export one closed-game snapshot to a dedicated handoff folder, receive it into a staging folder, and guide the player through manual placement. Automated placement or overwriting requires a change to those rules. Keep the live game folder out of the proposed sync flow.
